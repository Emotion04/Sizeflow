# 主题定制指南 — 通过 CSS 变量换色

> 目标：不碰逻辑代码，只改颜色/圆角/按钮样式。
> 原理：项目已用 `:root` CSS 变量统一主题，改变量即全局生效。

## 核心变量

文件：`static/css/main.css` 顶部 `:root`（约第 4-18 行）

| 变量 | 当前值 | 控制什么 |
|------|--------|---------|
| `--bg` | `#e8ecf1` | 页面背景底色 |
| `--glass` | `rgba(255,255,255,.72)` | 玻璃面板主色 |
| `--glass-hover` | `rgba(255,255,255,.85)` | 玻璃面板 hover |
| `--border` | `rgba(255,255,255,.5)` | 边框色 |
| `--text` | `#1a2332` | 主文字色 |
| `--text2` | `#5a6b7f` | 次要文字色 |
| `--primary` | `#4f6ef6` | **主色**（按钮/选中/强调/链接） |
| `--primary-h` | `#3b5ce0` | 主色 hover |
| `--danger` | `#e0556a` | 危险/错误色 |
| `--success` | `#2ea87a` | 成功色 |
| `--radius` | `14px` | 全局圆角 |
| `--shadow` | `0 8px 32px rgba(0,0,0,.06)` | 卡片阴影 |
| `--blur` | `18px` | 默认模糊度 |

## 常见换色场景

### 换整体主色（例如蓝 → 绿）
```css
--primary: #2ea87a;   /* 主色 */
--primary-h: #219a52; /* hover 更深 */
```

### 换背景色调
```css
--bg: #f0ebe3;  /* 暖米色背景 */
```

### 换按钮圆角
```css
--radius: 8px;  /* 更锐利 */
/* 或 20px → 更圆润 */
```

## 验证方法

1. 改 `:root` 里任意变量
2. 刷新页面
3. 观察按钮/选中/强调色是否全站跟随变化

## ⚠️ 已知"漏网之鱼"（改变量不会跟变的）

以下地方写死了颜色值，**未引用 `var()`**，换主色时不会自动跟随，需单独改：

1. **部分内联样式**：`index.html` 里有 105 处内联 `style=""`，其中少数直接写 `rgba(79,110,246,.xx)` 或 `#xxx`（如某些玻璃按钮 `background:rgba(79,110,246,.25)`）
2. **copywriter.js 模板字符串**：卖点图卡片等 UI 由 JS 字符串拼接，内部有写死颜色
3. **壁纸渐变**：Morandi 色系壁纸是独立数据（`sizechart.js` 的 `GRADIENT_WALLPAPERS`），与 `:root` 无关
4. **彩虹文字动画**（广告位）：6 色渐变写死在 index.html 内联样式

**结论**：换主题色 80% 场景改 `:root` 即可；剩下 20% 是上面这些写死色，需要针对性处理。若某处颜色不跟随，到对应位置改具体色值。
