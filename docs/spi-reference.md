## 排版逻辑

6 个文字框按固定位置覆盖在模板图上，每个位置对应一个卖点类别：

```
   右侧（3个）              左侧（2个）+ 右下（1个）
┌─────────────────────────────────────┐
│                                     │
│   ① 腰型 ──────────────→            │
│   ② 胯部 ──────────────→            │
│   ③ 版型总述 ──────────→            │
│                                     │
│            ←────── ④ 裤管版型       │
│            ←────── ⑤ 裤腿线条       │
│                         ⑥ 颜色面料  │
│                                     │
└─────────────────────────────────────┘
```

## 类别顺序

```
① 腰型 → ② 胯部 → ③ 版型总述 → ④ 裤管版型 → ⑤ 裤腿线条 → ⑥ 颜色面料
```

## 如何更新坐标

1. 用 https://www.image-map.net 在新图上框选 6 个区域
2. 复制 `<area coords="x1,y1,x2,y2">` 的像素值
3. 除以原图宽高得到归一化值：`x = x1 / 原图宽`，`y = y1 / 原图高`
4. 更新 `static/js/selling-point-image.js` 中的 `TEXTBOX_REGIONS` 数组
