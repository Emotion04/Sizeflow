# 文案风格分析

## 来源
用户提供的 10 条店铺文案（2026-06-19），类型1×5条 + 类型2×5条

---

## 类型1：详情页文案（标题 + 主体）

### 字数
- 标题：6-12 字
- 主体：120-180 字

### 结构模板
```
[标题：面料/颜色特征 + 裤型]
颜色/水洗描述 → 腰型/版型 → 上身效果(修饰) → 面料质感 → 搭配建议 → 氛围感收尾
```

### 语气
轻柔女性化，朋友聊天感，不硬推销。
高频词：修饰、线条、柔和、松弛、轻松、悄悄、自带、复古、清爽

### 句式
中长句自然流水，逗号连接。爱用「不...也...」句式。
无感叹号、无emoji、无数值规格、无极限词。

---

## 类型2：卖点文案（参数 + 卖点陈列）

### 首行参数
```
颜色：[AI从图片识别，如"怀旧色""复古蓝""白色"]
面料成分：[留空，不生成]
弹力指数：[留空，不生成]
版型类型：[留空，不生成]
厚度指数：适中
柔软指数：适中
```

### 卖点结构
每条版本 = 首行参数 + 4个卖点
每个卖点 = 标题（6-10字）+ 描述（25-40字）

四个卖点通常按以下顺序：
1. 腰型/版型设计 + 上身效果
2. 面料质感 + 穿着感受
3. 裤型剪裁 + 修饰效果
4. 颜色/做旧/细节 + 风格氛围

### 卖点标题示例
- 中高腰设计
- 舒适微弹牛仔面料
- 直筒微喇型剪裁
- 复古做旧质感
- 中腰立体剪裁
- 有弹修身面料
- 质感竹节纹面料

### 卖点描述特点
25-40字，一句或两句自然衔接。无感叹号无emoji。
"提拉腰线，优化腰臀比例，轻松打造三七分身材"（高频句式）
"不紧绷""不束缚""不挑腿型""不勒肉不压胯"（否定式卖点）

### 禁忌
同类型1：无感叹号、无极限词、无emoji、无强制推销语
